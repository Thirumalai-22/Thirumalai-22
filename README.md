## 🧪 Academic & Research Work

### ❤️ Heart Disease Classification

Machine Learning comparison using the Cleveland UCI Heart Disease dataset.

| Algorithm | Accuracy |
|---|---:|
| Random Forest | **81.8% ± 4.5%** |
| K-Nearest Neighbors (KNN) | 81.1% |
| Decision Tree | 76.1% |

- Dataset: 302 records.
- Evaluation: Stratified 5-fold cross-validation.
- Used scaling inside a Pipeline to prevent data leakage.
- Reviewed 10 published studies.
- Identified important features including chest pain type, maximum heart rate, major vessels, thal and ST depression.

**Tools:** Python, Jupyter Notebook, pandas, NumPy, matplotlib and scikit-learn.
